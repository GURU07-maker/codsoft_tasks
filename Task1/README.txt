Task 1: To-Do List Application

Description:-
A simple command-line To-Do List application written in Python. It allows users to add, view, update, and delete tasks while the program is running.

Features:-
- Add a new task.
- View all tasks with their numbers.
- Update a task by entering its task number.
- Delete a task by entering its task number.
- Exit the application.

Requirements:-
- Python 3
- No external libraries are required.

How to Run:-
This project is provided as a Jupyter Notebook (`TASK 1.ipynb`).

1. Open the notebook in Jupyter Notebook, JupyterLab, or VS Code.
2. Run the code cell.
3. Follow the menu displayed in the output and enter your choice.

How to Use:-
Choose an option from the menu:
- `1` to add a task.
- `2` to view tasks.
- `3` to update a task.
- `4` to delete a task.
- `5` to exit.

Concepts Used:-
Python lists, `while` loop, `for` loop, conditional statements, `input()`, `print()`, `append()`, and `pop()`.

Note:-
Tasks are stored in a list in memory. They are not saved to a file, so they are lost when the program stops.
