# Task 4: Rock Paper Scissors Game

## Description
A command-line Rock Paper Scissors game written in Python. The user plays against the computer, which randomly chooses rock, paper, or scissors.

## Features
- Lets the user choose rock, paper, or scissors.
- Generates a random choice for the computer.
- Determines whether the round is a win, loss, or tie.
- Tracks the user's and computer's scores.
- Allows the user to play multiple rounds.
- Displays the final scores when the user stops playing.

## Requirements
- Python 3
- Python standard-library module: `random`
- No external installation is required.

## How to Run
This project is provided as a Jupyter Notebook (`TASK 4.ipynb`).

1. Open the notebook in Jupyter Notebook, JupyterLab, or VS Code.
2. Run the code cell.
3. Enter `rock`, `paper`, or `scissors` when prompted.
4. Enter `yes` when asked to play another round, or another response to stop.

## Game Rules
- Rock beats scissors.
- Scissors beat paper.
- Paper beats rock.
- If both choices are the same, the round is a tie.

## Concepts Used
Python lists, variables, `while` loop, `if-elif-else`, `continue`, `break`, score counters, and `random.choice()`.

## Note
The scores are kept in memory while the game is running and are not saved after the program stops.
