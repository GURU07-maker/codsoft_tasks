Task 2: Simple Calculator

Description:-
A basic calculator written in Python. It asks the user for two numbers and an operation, then displays the result.

Features:-
- Addition
- Subtraction
- Multiplication
- Division
- Checks for division by zero.
- Displays a message for an invalid operation choice.

Requirements:-
- Python 3
- No external libraries are required.

How to Run:-
This project is provided as a Jupyter Notebook (`TASK 2.ipynb`).

1. Open the notebook in Jupyter Notebook, JupyterLab, or VS Code.
2. Run the code cell.
3. Enter the first number and the second number.
4. Select an operation using `1`, `2`, `3`, or `4`.

How to Use:-
- `1` performs addition.
- `2` performs subtraction.
- `3` performs multiplication.
- `4` performs division.

Concepts Used:-
Python variables, `float()`, `input()`, `print()`, arithmetic operators, and `if-elif-else` conditional statements.

Note:-
The calculator performs one calculation each time the code cell is run.
